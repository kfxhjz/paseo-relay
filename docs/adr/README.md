# Architecture decision records

**English** | [简体中文](../zh-CN/adr-summary.md)

ADRs record decisions that are expensive to reverse. They are immutable in
intent: a later ADR supersedes an earlier one rather than rewriting it.

| ADR | Decision | Status |
|---|---|---|
| [0001](0001-single-node-edge-hashing.md) | Single-node relay; edge consistent hashing on `serverId` | Accepted |
| [0002](0002-custom-rfc6455-codec.md) | Custom server-side RFC 6455 codec | Accepted |
| [0003](0003-no-relay-authentication.md) | No relay-level authentication by design | Accepted |
